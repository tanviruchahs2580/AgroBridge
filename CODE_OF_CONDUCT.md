# Code of Conduct

## Our standard

Be professional and constructive. We review each other's work, argue about
technical decisions, and write in two languages — treat people better than code.

## Expected behaviour

- Assume good intent; criticise code, not people.
- Keep discussions on the issue or PR where they started.
- Write feedback a person far away and far later can act on: what to change and why.

## Unacceptable behaviour

- Harassment, insults, or personal attacks in any language.
- Publishing private information (ours or a farmer's) — this repository handles
  real agricultural data; PII discipline is a conduct matter, not just a security one.
- Deliberately shipping code that fabricates data the product presents to farmers.

## Enforcement

Report violations to the maintainers listed in SECURITY.md (or privately to any
maintainer). Every report is acknowledged within the SECURITY.md response window.
Repeated or severe violations result in a ban from the repository and its spaces.

This policy is adapted from the Contributor Covenant; disputes about its
application are resolved by the repository owner, whose decision is final.
