## 1) What This Version Is

This is the **easy, specific farmer dashboard** that was live at the time of the `ROOT CAUSE ANALYSIS + FIX + SERVICE IMAGE INTEGRATION` report — before the complex 12-screen `28°C` Home was introduced. It is intentionally kept **simple for smallholder farmers** and is now the **official revert base**.

**Includes (from that report):**
- **Home Dashboard (Easy):** AI Farm Status hero `87%` (`FARM_HERO_IMG` + `HealthRing` photographic, `HealthScore` pulsating, `87%`/`72%` fallback), 4-card grid (`আজকের কাজ` 4 tasks, `আবহাওয়া` `29.5°` live, `চলমান ফসল` `ধান` + `বৃদ্ধি পর্যায়ে` pill, `ওয়ালেট` `২,৫০০৳` live), `AI Ask` large prompt (`Ask AgroBridge AI`), `দ্রুত সেবা` 4 (AI, Services, Sell, Notifications with badge), `Smart Alerts` 2 (rain/pest) — *not* the later `28°C` 8-action complex Home.
- **Login (Easy):** Simple `Sprout` centered `Card` (`phone` + `password` only, `+880` placeholder, `Demo` hint in DEV) — *not* the splash hero with Google/FB that was harder for farmers.
- **MyFarm (Easy):** Simple `Tractor` header + `addFarm` + `Card` farm/plot/crop forms — *not* the `12.5/3/2` stats + `72×72` image list that was added later for the 12-screen realize.
