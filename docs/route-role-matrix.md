# Route × role matrix

> Generated by `apps/api/scripts/generate-route-matrix.mjs` — do not edit.
> Regenerate: `node apps/api/scripts/generate-route-matrix.mjs`.
> Drift gate: `apps/api/tests/route-role-matrix.test.ts` compares this file with a fresh in-memory render.

Auth values:

- `guard: module` — a module-level `router.use(requireAuth)` covers every route registered below it.
- `guard: route` — `requireAuth` is listed on that route.
- `public` — deliberately unauthenticated; the reason is listed below and enforced by the generator.

Roles are derived from `src/middleware/rbac.ts`: a `requirePermission` route lists every role whose permission set contains the key (`SUPER_ADMIN` holds `*`, so it appears everywhere).

## Public routes (explicit allowlist)

| Route | Reason |
|---|---|
| `ALL /payments/gateway/return/:outcome` | hosted-checkout browser return; trusts nothing in the request — the outcome is decided by asking the provider, the webhook remains the primary path |
| `GET /membership/plans` | public tier catalogue (price/benefits only, no user data); shown before login to drive sign-up |
| `POST /auth/login` | credential exchange itself; login limiter plus per-account throttle, uniform error and timing profile |
| `POST /auth/password/forgot` | self-service recovery for a caller who cannot log in; always-200 response hides account existence |
| `POST /auth/password/reset` | completes recovery with the OTP issued by /auth/password/forgot; success revokes every refresh token |
| `POST /auth/refresh` | the refresh token is the credential; rotation with reuse detection revokes the family |
| `POST /auth/register` | account creation happens before any session exists; protected by the register limiter and schema validation, and duplicate phones get a neutral response (no enumeration oracle) |
| `POST /payments/webhook/sslcommerz` | gateway IPN; unauthenticated by contract and verified by the provider signature (constant-time) plus amount/currency checks |
