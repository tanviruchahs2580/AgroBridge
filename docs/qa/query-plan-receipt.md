# Query plan receipt (ARC-15)

Generated by `apps/api/scripts/query-receipts.mjs` against the SQLite suite database
(`prisma/test.db` after the test global setup). Plans are engine-specific — PostgreSQL
plans for the production database must be captured separately (owner's database).

### products list: isActive filter + newest-first + LIMIT cap

```sql
SELECT * FROM "Product" WHERE "isActive" = 1 ORDER BY "createdAt" DESC LIMIT 12
```

```
SEARCH Product USING INDEX Product_isActive_category_idx (isActive=?) | USE TEMP B-TREE FOR ORDER BY
```

### notifications: unread critical count per user

```sql
SELECT COUNT(*) FROM "Notification" WHERE "userId" = 'u1' AND "readAt" IS NULL AND "category" = 'CRITICAL'
```

```
SEARCH Notification USING INDEX Notification_userId_readAt_idx (userId=? AND readAt=?)
```

### wallet: ledger sum per user (reconciler hot path)

```sql
SELECT SUM("amountPaisa") FROM "WalletTransaction" WHERE "userId" = 'u1' AND "direction" = 'CREDIT'
```

```
SEARCH WalletTransaction USING INDEX WalletTransaction_userId_idx (userId=?)
```

### orders: capped newest-first per user

```sql
SELECT * FROM "Order" WHERE "userId" = 'u1' ORDER BY "createdAt" DESC LIMIT 20
```

```
SEARCH Order USING INDEX Order_userId_createdAt_idx (userId=?)
```

### farm events: per farm, newest first

```sql
SELECT * FROM "FarmEvent" WHERE "farmId" = 'f1' ORDER BY "occurredAt" DESC LIMIT 50
```

```
SEARCH FarmEvent USING INDEX FarmEvent_farmId_idx (farmId=?) | USE TEMP B-TREE FOR ORDER BY
```
