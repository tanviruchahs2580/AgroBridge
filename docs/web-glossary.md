# bn/en product glossary (WEB-04)

Canonical Bengali ↔ English product terms. The bn column fixes WHICH word a
concept maps to, so the same English idea never oscillates between two Bengali
words across screens; the i18n keys continue to hold the actual text.
Native sign-off on this table is owner-bound (native-Bangla reviewer).
